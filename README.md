# Mini Project on Pizza Sales Data Using Linear Regression

## 📌 Overview

A beginner-friendly Machine Learning mini project that uses **Linear Regression** to predict pizza prices based on pizza size.

## 🎯 Objective

* Analyze the relationship between pizza size and price.
* Train a Linear Regression model.
* Visualize the regression line.
* Predict prices for new pizza sizes.

## 📊 Dataset

The dataset contains:

* `pizza_size` — Pizza size in inches
* `pizza_price` — Pizza price in ₹

## 🛠️ Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## 🤖 Model

**Linear Regression**

**Input:** Pizza Size
**Target:** Pizza Price
